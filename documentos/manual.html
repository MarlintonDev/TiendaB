1. Instalación del Entorno

Siga estos pasos para configurar su estación de trabajo profesional:

  1. Descargue el instalador en python.org.

B. Extensiones Esenciales en VS Code

  • Esencial Python (Microsoft): El motor principal.

  • Recomendada Code Runner: Para ejecutar con un solo clic.

Cálculos y Ciclos

# Calcular el total

    print("1. Vender \n0. Salir")

        break

Gestión con Diccionarios (Inventario)

# 1. Crear inventario
inventario = {"arroz": 20, "leche": 10, "pan": 15}

# 2. Descontar valor tras venta
inventario["arroz"] = inventario["arroz"] - cantidad

# 3. Recorrer y mostrar
for prod, stock in inventario.items():
    print(f"Producto: {prod} | Stock: {stock}")
